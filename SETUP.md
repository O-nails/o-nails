# O.nails — исправленное бронирование Supabase

1. Откройте Supabase → SQL Editor.
2. Запустите **весь** `supabase.sql` из этого архива.
3. В `index.html` внизу проверьте `window.ONAILES_SUPABASE`: URL проекта и publishable/anon key.
4. Загрузите `index.html`, `script.js` и папку `assets` на хостинг.

После этого сайт:
- загружает занятые даты из Supabase;
- сохраняет бронь через серверную RPC-функцию;
- не позволяет двум клиентам занять один день;
- работает только Пн–Пт в 16:00;
- после успешной записи открывает Telegram с заполненным сообщением.

Если Supabase вернёт ошибку, сайт теперь показывает точный текст ошибки, а не только общее сообщение.
